# Apple System Pass: Feed + Dock Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make Spark's Feed screen and bottom dock feel like a native iOS system app — system typography, translucent glass materials, unified press motion — while keeping the lavender accent and existing behavior exactly intact.

**Architecture:** Presentation-only change. `theme.ts` gains a platform-aware system-font helper (San Francisco on iOS via RN's `'System'` family, bundled Inter elsewhere) and a new `glass` token set. A new shared `GlassSurface` component wraps `expo-blur`'s `BlurView` with the correct tint/intensity/border per surface tier, rendered as a decorative absolute-fill layer behind existing icons/content. `FeedScreen`, `FactCard`, and `BottomDock` swap their solid `bgAlt` + `shadows.card`/`shadows.sheet` surfaces for `GlassSurface`, with no changes to layout geometry, event handlers, or store wiring.

**Tech Stack:** Expo 54 / React Native 0.81 / TypeScript. New deps: `expo-blur`, `@expo-google-fonts/inter`. Removed dep: `@expo-google-fonts/manrope` (confirmed unused outside `theme.ts` once typography tokens change — see Task 2).

- The lavender accent (`colors.accentPrimary`, `#8A82C4`) remains the only solid, fully-saturated surface. The Dive Deeper dock button stays a solid filled circle; every other surface touched in this plan becomes translucent glass.

```ts
// Inter is the Android/web substitute for San Francisco — same grotesque-
// sans geometry family (tall x-height, rounded terminals), the standard
// stand-in apps use since Apple doesn't license SF Pro off-platform. Loaded
// per-weight like Manrope was: RN can't synthesize weight from one custom
// font file, only from the 'System' family, which resolves to true San
// Francisco on iOS and supports RN's fontWeight prop directly there.
const interWeights = {
  regular: 'Inter_400Regular',
  medium: 'Inter_500Medium',
  semiBold: 'Inter_600SemiBold',
  bold: 'Inter_700Bold',
} as const

const systemWeightNumeric: Record<keyof typeof interWeights, '400' | '500' | '600' | '700'> = {
  regular: '400',
  medium: '500',
  semiBold: '600',
  bold: '700',
}

function systemFont(weight: keyof typeof interWeights) {
  return Platform.OS === 'ios'
    ? { fontFamily: 'System', fontWeight: systemWeightNumeric[weight] }
    : { fontFamily: interWeights[weight] }
}
```

### Task 3: GlassSurface component

**Files:**
- Create: `src/components/GlassSurface.tsx`

**Interfaces:**
- Consumes: `glass` from `../theme` (Task 2).
- Produces: `GlassSurface({ variant: 'chrome' | 'dock', radius: number, style?: StyleProp<ViewStyle> })` — a decorative, absolutely-positioned, non-interactive blur layer. Callers render it as the first child of the surface it's backing (icon/content renders after it, visually on top).

- [ ] **Step 1: Write the component**

```tsx
import { BlurView } from 'expo-blur'
import { StyleSheet, View, type StyleProp, type ViewStyle } from 'react-native'
import { glass } from '../theme'

interface GlassSurfaceProps {
  variant: keyof typeof glass
  radius: number
  style?: StyleProp<ViewStyle>
}

// Decorative, absolutely-positioned blur layer — render as the first child
// of whatever Pressable/View it's backing, with the icon/content rendered
// after it so the content stays visually on top. pointerEvents="none" so
// this layer never intercepts the touch meant for its parent.
export function GlassSurface({ variant, radius, style }: GlassSurfaceProps) {
  const config = glass[variant]
  return (
    <View
      pointerEvents="none"
      style={[
        StyleSheet.absoluteFill,
        {
          borderRadius: radius,
          borderWidth: 1,
          borderColor: config.borderColor,
          overflow: 'hidden',
        },
        style,
      ]}
    >
      <BlurView intensity={config.intensity} tint={config.tint} style={StyleSheet.absoluteFill} />
    </View>
  )
}
```
